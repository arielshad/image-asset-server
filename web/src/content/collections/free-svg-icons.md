## One search over 200 icon sets

Iconify collects over 200,000 icons from about 200 open-source sets: Material Symbols, Tabler, Phosphor, Lucide, Remix, Carbon, Font Awesome Free and many more. Each icon is a clean SVG that scales to any size and takes your text colour.

This page shows icons for a common word; search for your own ("upload icon", "rocket", "weather") to find matching symbols across every set at once, and compare styles side by side: outline, filled, duotone, rounded.

## Using them

Download the SVG from the detail view, or reference Iconify's file URL directly in your build. Stick to one set within an interface so stroke widths and corner radii match. Check the licence shown on each icon: most sets are MIT or Apache 2.0, a few are CC BY.
